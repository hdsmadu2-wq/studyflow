# studyflow
# Aplikasi Kuis Interaktif

Implementasi proyek kolaborasi pemrograman Kelas XII menggunakan Python.

## Fitur MVP
- Nama pemain
- Pemilihan jumlah soal
- Randomisasi soal
- Pilihan ganda
- Validasi input
- Skor otomatis
- Feedback hasil
- Penyimpanan skor dengan JSON
- Leaderboard

## Struktur Tim
1. Programmer/Logic
2. UI/UX
3. Data & File I/O
4. Tester & Dokumentasi

## Menjalankan
Pastikan Python 3 terpasang, lalu:
`python main.py`

## Pengembangan tahap berikutnya
- Kategori soal
- Tingkat kesulitan
- Timer setiap soal
- GUI Tkinter/PySide
- Login pengguna
- Ekspor hasil CSV/PDF
- Versi web
